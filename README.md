## 《臺灣在呼吸》

全螢幕的生成畫面加 Web Audio。背景微地動被聽成一陣持續的呼吸；事件脈衝進來時，低音下墜、短促的高頻，還有向外的圓，和呼吸明顯不同。

怎麼聽：

1. 按「開始聲音」。瀏覽器規定要有這個動作才出聲。建議耳機，音量先調小。
2. 空白鍵同樣能開關聲音。`E` 或「送入事件脈衝」會立刻送一記事件。
3. 「聽感」換的是週期、厚薄與濾波，是預設，不是那座測站的實測。
4. 「事件強度」只改變脈衝的聲音與畫面，不改寫示範波形本身。
5. 示範迴圈約 72 秒，裡面本來就有兩記事件（約 18.5 秒與 47 秒）。

資料預設是「模擬／示範資料」：`breathing/sample-wave.json`。讀不到檔案時，瀏覽器會用同一支 `breathing/wave.js` 再合成一次。波形是可循環的微地動式正弦，加上一點衰減雜訊與兩記小波，不是任何測站的紀錄。

### 以後接上真的波形

頁面上選「即時橋接」，填 `ws://` 或 `wss://`，或直接開 `breathing/?ws=wss://你的橋接`。這個網站不內建網址、帳號或金鑰，預設也不會對外連線。

橋接請送 JSON 文字框，不要送二進位：

```json
{"type":"hello","station":"HUAL"}
{"type":"samples","dt":0.025,"samples":[0.02,-0.01,0.03]}
{"type":"event","id":"可省略","amplitude":1.0}
```

`samples` 大致落在 −1 到 1。`event` 會觸發和「送入事件脈衝」同一套聲音與畫面。若只有波形、沒有 `event`，絕對值穿出 0.92 且超過 8 秒沒有事件時，客戶端會自己補一記，避免漏掉明顯的脈衝。佇列超過約 5 秒會丟掉舊樣本，維持接近即時。

SeedLink 與 ObsPy 跑在瀏覽器外面。橋接自己連線、自己保管帳號，再把上面這種 JSON 轉給網頁。Pages 不會執行這段，這裡只留接點：

```python
# 可選。需要另外安裝：pip install obspy websockets
# import asyncio, json, websockets
# from obspy.clients.seedlink.easyseedlink import create_client
#
# async def handler(websocket):
#     await websocket.send(json.dumps({"type": "hello", "station": "DEMO"}))
#     # 在 SeedLink 的 callback 裡：
#     # await websocket.send(json.dumps({
#     #     "type": "samples",
#     #     "dt": 1 / trace.stats.sampling_rate,
#     #     "samples": trace.data[-40:].tolist(),
#     # }))
#
# 客戶端程式在 breathing/source.js 的 SeismicSource。
# 預設模式是 Demo loop；setMode("ws", url) 才會連線。
```

重新產生示範檔：

```bash
node breathing/make-sample.mjs
```

## 《預警的十秒》

選城市，重播 2024-04-03 花蓮地震。地圖上有 P 波與 S 波的示意波前，旁邊倒數下一個關鍵時刻，並在 P 波、國家級警報、S 波各給一個這頁自己做的音。那個音不是災防告警系統的聲音。

建議先按三個情境：

| 情境 | 城市 | 這頁要講的事 |
| --- | --- | --- |
| 有預警 | 宜蘭 | 警報早於本地 P 波，之後還有二十幾秒才到 S 波 |
| 盲區 | 花蓮 | 國家級警報有發，但和 S 波幾乎同時 |
| 未發警報 | 臺北 | 搖得到，手機國家級警報沒有響 |

切換下方的城市不會把時間倒回，方便停在同一秒比較。三個情境鈕與「重播」會從發震再開始。空白鍵播放／暫停，左右方向鍵換城市。手機上按鈕夠大，地圖在上方，時間在下方。

「示意搖晃」只表示遠近，不換算氣象署震度。

## 第二件作品的資料與假設

事件取 2024-04-03 07:58:09.9（臺灣時間），ML 7.2，深度 15.5 公里，震央 23.77°N、121.67°E。這組定位是該次地震公開報告常用的數值，花蓮市到震央約 25 公里，和「花蓮縣政府南南東方 25 公里」同一個數量級。

國家級警報的縣市與鐘面，依交通部中央氣象署 113 年 4 月 3 日新聞稿（中象 113 字第 11 號）：

- 07:58:18（發震後 8.1 秒）：花蓮、宜蘭、南投、彰化
- 07:58:24（發震後 14.1 秒）：臺中、苗栗、新竹縣、雲林、嘉義縣、嘉義市、臺南、臺東
- 未發國家級警報：臺北、新北、基隆、桃園、新竹市、高雄、屏東

新聞稿說明初報規模為 6.2 與 6.8，預估震度未達 4 級，所以前述縣市沒有國家級警報。電視台插播與部分網路通報另有發出。這頁的聲音只代表手機國家級警報。高雄市以新聞稿的縣市層級為準，觀察點取市中心；NCREE 彙整另列山區鄉鎮，頁面上有註明。

到時是教學用均質地殼，不是作業走時表：

- 城市用約略的行政中心，不是地震站
- 震源距 = √(震央距² + 15.5²)，震央距為大圓距離
- P 波到時 = 震源距 / 6.2 km/s
- S 波到時 = 震源距 / 3.5 km/s
- 可應變時間 = S 波到時 − 警報時刻
- 可應變時間少於 5 秒，這頁稱為預警盲區

和真實到時可以差數秒。波前畫的是地表第一達的半徑 √((v×t)² − 深度²)。

在這組假設下，幾個城市是：

| 城市 | 震央距 | P 波 | S 波 | 國家級警報 | 可應變 |
| --- | ---: | ---: | ---: | --- | ---: |
| 花蓮市 | 25 km | 4.8 s | 8.4 s | 8.1 s | 0.3 s，盲區 |
| 宜蘭市 | 110 km | 17.8 s | 31.6 s | 8.1 s | 23.5 s |
| 南投市 | 101 km | 16.5 s | 29.3 s | 8.1 s | 21.2 s |
| 臺中市 | 110 km | 17.8 s | 31.6 s | 14.1 s | 17.5 s |
| 臺北市 | 141 km | 22.9 s | 40.5 s | 未發 | — |
| 新竹市 | 135 km | 21.9 s | 38.9 s | 未發 | — |
| 竹北（新竹縣） | 136 km | 22.0 s | 39.1 s | 14.1 s | 25.0 s |
| 臺南市 | 172 km | 27.8 s | 49.2 s | 14.1 s | 35.1 s |
| 高雄市 | 189 km | 30.6 s | 54.2 s | 未發 | — |

其餘城市由 `ten-seconds/scenario.js` 用同一套式子現算，頁面上的簡述就是那些數字。檢查：

```bash
node ten-seconds/check.mjs
```

## 開啟 GitHub Pages

倉庫目前沒有 Pages 站點。這個環境的權限無法替你按下設定，合併此變更到 `main` 之後，請倉庫管理員做一次：
